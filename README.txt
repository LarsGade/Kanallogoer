KANALLOGOER – GitHub Pages

1. Pak ZIP-filen ud.
2. Upload indholdet til roden af dit GitHub-repository (index.html skal ligge i roden).
3. Åbn Settings → Pages. Vælg Deploy from a branch, din branch og / (root). Tryk Save.
4. GitHub viser adressen, når hjemmesiden er udgivet.

Du kan også åbne index.html direkte på din computer.

Pakken indeholder de 36 oprindelige logoer fra hjemmesidens kildekode. Senere uploadede logoer og ændringer i rækkefølgen er ikke med; de kunne ikke hentes fra den aktive hjemmeside.

Tilføj billeder i assets/ og tilføj deres navn og sti i logos.js. Rækkefølgen i logos.js bestemmer rækkefølgen på siden.

Dette er en statisk hjemmeside uden login eller admin-upload. Ingen server, adgangskoder eller forbindelse til larsgade.com er nødvendig. Klik på et logo for at åbne eller hente billedet.

Kopier-knappen under hvert logo kopierer den fulde billedadresse. På GitHub Pages bliver det et offentligt HTTPS-link; åbner du index.html lokalt, er adressen en lokal filsti.
